🚀 Web Scraper GUI

A modern GUI web scraper that extracts data from websites and exports it in multiple formats.

📋 Features

🌐 Scrape any website

📊 Real-time data preview

💾 Export to CSV/JSON/Excel

📈 Statistics generation

📝 Activity logging

🛠️ Installation


git clone https://github.com/yourusername/web-scraper.git
cd web-scraper
pip install -r requirements.txt
requirements.txt:

beautifulsoup4==4.12.2
requests==2.31.0
pandas==2.1.4
openpyxl==3.1.2

🚀 Usage

python scraper_gui.py
Quick Steps:
Enter website URL

Set pages/items to scrape

Click "Start Scraping"
